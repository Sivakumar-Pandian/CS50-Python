Problem: Making Faces

Write a Python program that converts emoticons in a string to emoji.

Details:

Implement a function called convert that:

Accepts a string as input

Replaces any :) with 🙂 (slightly smiling face)

Replaces any :( with 🙁 (slightly frowning face)

Returns the resulting string

Implement a function called main that:

Prompts the user for input

Calls convert on that input

Prints the result

Be sure to call main at the bottom of your file.

All other text should remain unchanged.

Examples:
Input: Hello :)
Output: Hello 🙂

Input: Goodbye :(
Output: Goodbye 🙁

Input: Hello :) Goodbye :(
Output: Hello 🙂 Goodbye 🙁
