Problem: Indoor Voice

Write a Python program that takes a line of text as input and outputs the same text in lowercase.

Details:

The program should convert all uppercase letters to lowercase.

Punctuation, numbers, and spaces should remain unchanged.

You may include a custom prompt for input.

Examples:
Input: HELLO
Output: hello

Input: THIS IS CS50
Output: this is cs50

Input: 50
Output: 50
