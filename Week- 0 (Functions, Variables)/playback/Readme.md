Problem: Playback Speed

Write a Python program that takes a line of text as input and outputs the same text, replacing each space with three periods (...).

Details:

Every space between words should be replaced by three periods.

All other characters should remain unchanged.

Examples:
Input: This is CS50
Output: This...is...CS50

Input: This is our week on functions
Output: This...is...our...week...on...functions

Input: Let's implement a function called hello
Output: Let's...implement...a...function...called...hello
